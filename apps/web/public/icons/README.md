# 应用入口图标

`app.svg` 复用页面顶栏的原创面包路径，采用品牌浅金到暖橙渐变与深棕标志。它是图标源文件，不依赖字体、外部图片或网络资源。

PNG 由该 SVG 在浏览器原生 Canvas 中按目标尺寸绘制并导出，保持不透明、无预先裁切的圆角：

| 文件                      | 尺寸    | 用途                          |
| ------------------------- | ------- | ----------------------------- |
| `favicon-32.png`          | 32×32   | 浏览器标签图标回退            |
| `../apple-touch-icon.png` | 180×180 | Apple 主屏幕图标              |
| `app-192.png`             | 192×192 | manifest 普通图标             |
| `app-512.png`             | 512×512 | manifest 普通及 maskable 图标 |

修改源文件后同时重新导出四档 PNG，并核对 manifest、HTML 链接、实际 MIME/尺寸与构建产物。512px 版本的深棕标志应完整位于中心半径 204.8px 的圆内，圆形裁切后的背景由平台处理；不把已有 PNG 再拉伸生成大图。此次验收实际统计圆外深棕像素为零、透明像素为零，512px 图已目视检查。
