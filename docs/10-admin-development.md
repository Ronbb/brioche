- 角色：角色快照、头像关联、姓名和法语语音 locale；新版本不能更改已发布快照。
- 录音：上传、来源与授权、解码校验、时间轴和正文对应、固定版本登记及试听。
- 账号：列表、邀请、重置链接、权限与会话管理；一次性链接只向当前管理员显示，不写日志，不自动发送邮件。权限变更应保护最后一位管理员并即时生效。

不把容器控制、任意 SQL 或 shell 命令作为网页后台能力。现有 CLI 业务检查应被复用，页面操作不能绕过不可变版本、发布校验或事务。

## 登录会话管理

撤销当前浏览器时服务端清除当前认证，网页明确提示会退出、停止播放器并转到登录页；其他会话不受影响。既有SessionStore的save只更新仍存在且未过期的记录，不允许迟到响应重新插入被撤销会话。撤销保证后续请求无法再登录，不声称回滚已经开始的其他业务操作。
