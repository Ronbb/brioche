# 管理员后台开发目标

2026-10-07 用户明确要求新增管理员后台、从个人页进入并支持现有全部后台管理功能。此目标属于当前「完成所有功能」活动目标，尚未完成；已有 `/author-preview` 不能代替管理后台。

入口为个人页的「管理员后台」，服务端每次请求验证当前 operator 身份，所有写入经过现有 Origin 与会话 CSRF 校验。普通学习者不能依靠直接输入 URL 获取后台数据。页面与响应保持 private/no-store。

范围：

- 课程：目录顺序、草稿导入、固定版本预览、批准/退回及理由、审校历史；课程源不作为公共静态资源，私有答案不返回列表。
- 发布：检查批准状态与素材、建立 staging 目录、预览、按 generation 激活或回滚、撤回固定课程版本。批准与上线状态分别显示。
- 素材：插图与头像上传、来源/作者/许可记录、哈希与尺寸校验、固定版本登记、私有预览；授权声明需真实填写。
- 角色：角色快照、头像关联、姓名和法语语音 locale；新版本不能更改已发布快照。
- 录音：上传、来源与授权、解码校验、时间轴和正文对应、固定版本登记及试听。
- 账号：列表、邀请、重置链接、权限与会话管理；一次性链接只向当前管理员显示，不写日志，不自动发送邮件。权限变更应保护最后一位管理员并即时生效。
- 操作记录：当前管理员作为真实 actor，理由、操作对象、结果与时间；不能由浏览器自由冒充 actor。写入并发与失败重试须有明确语义。

不把容器控制、任意 SQL 或 shell 命令作为网页后台能力。现有 CLI 业务检查应被复用，页面操作不能绕过不可变版本、发布校验或事务。

## 待使用链接管理（2026-10-07）

账号管理进入 `/admin/tokens`，列出未消费且未过期的学习者/管理员邀请与密码重置链接，可按类型筛选，20条游标分页。列表只包含邮箱、类型、邀请角色、到期时间和由认证哈希再SHA-256得到的管理编号，不返回原始token、认证哈希或可恢复的链接；原链接继续只在发放时显示。

撤销须填写理由。事务按account-admin→邮箱锁顺序，重新验证operator；与发放、注册和密码重置消费共用邮箱锁，撤销和消费只有一方能成功。成功将记录标记不可再使用，并与不可变审计同事务提交；已失效返回404，不重复写审计。撤销重置链接不修改用户密码，不退出已有会话；允许继续发放新的链接。

## 登录会话管理

账号列表的「登录会话」进入 `/admin/accounts/:accountId/sessions`。列表每页20条，仅显示这个账号尚未过期且已认证的会话，标识当前浏览器并显示中国时间的到期时间；数据库尚未记录设备名称/最后访问时间，不伪造这些信息。SSR与API均验证当前operator，私有缓存禁用，游标只转发afterId。

会话标识是数据库内SHA-256记录键，不能用于登录；列表不返回Cookie、session原始ID、认证哈希、CSRF、密码或session数据。撤销请求绑定目标账号与记录键，事务取得account-admin锁后复核operator，删除记录并追加不可变审计，理由必填。已经不存在的会话返回404，刷新核对，不重复追加审计。

撤销当前浏览器时服务端清除当前认证，网页明确提示会退出、停止播放器并转到登录页；其他会话不受影响。既有SessionStore的save只更新仍存在且未过期的记录，不允许迟到响应重新插入被撤销会话。撤销保证后续请求无法再登录，不声称回滚已经开始的其他业务操作。

隔离PostgreSQL已验证访客/学习者/CSRF权限、跨账号撤销拒绝、单会话撤销后其他会话仍有效、重复撤销无重复审计、当前会话退出、20→6分页及过期过滤；既有SessionStore迟到保存回归通过。包括角色库在内的完整6项构建页面浏览器116.91秒通过；17SSR、29Web、9Qwen协议测试、TS7、Clippy/fmt、Rust工作区常规测试和本批管理员/PostgreSQL隔离测试通过。生产已实际更新API/Web及迁移14，备份数据库和5媒体verify，两HTTPS入口健康；未修改真实账号角色或撤销用户会话。
