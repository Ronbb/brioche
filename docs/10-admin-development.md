# 管理员后台开发目标

2026-10-07 用户明确要求新增管理员后台、从个人页进入并支持现有全部后台管理功能。此目标属于当前「完成所有功能」活动目标，尚未完成；已有 `/author-preview` 不能代替管理后台。

入口为个人页的「管理员后台」，服务端每次请求验证当前 operator 身份，所有写入经过现有 Origin 与会话 CSRF 校验。普通学习者不能依靠直接输入 URL 获取后台数据。页面与响应保持 private/no-store。

范围：

- 课程：目录顺序、草稿导入、固定版本预览、批准/退回及理由、审校历史；课程源不作为公共静态资源，私有答案不返回列表。
- 发布：检查批准状态与素材、建立 staging 目录、预览、按 generation 激活或回滚、撤回固定课程版本。批准与上线状态分别显示。
- 素材：插图与头像上传、来源/作者/许可记录、哈希与尺寸校验、固定版本登记、私有预览；授权声明需真实填写。
- 角色：角色快照、头像关联、姓名和法语语音 locale；新版本不能更改已发布快照。
- 录音：上传、来源与授权、解码校验、时间轴和正文对应、固定版本登记及试听。
- 账号：列表、邀请、重置链接、权限与会话管理；一次性链接只向当前管理员显示，不写日志，不自动发送邮件。权限变更应保护最后一位管理员并即时生效。
- 操作记录：当前管理员作为真实 actor，理由、操作对象、结果与时间；不能由浏览器自由冒充 actor。写入并发与失败重试须有明确语义。

不把容器控制、任意 SQL 或 shell 命令作为网页后台能力。现有 CLI 业务检查应被复用，页面操作不能绕过不可变版本、发布校验或事务。
