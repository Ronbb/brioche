# 角色与声音档案

角色库入口为 `/admin/characters`，从管理员后台进入，只有当前 operator 能读取和修改。姓名、头像和法语 locale 保存为不可变 `character_revisions`；头像文件通过有权限的接口读取，登记未发布的头像不会因此变成公共文件。网页可新建角色或修改姓名/头像以追加新版本；CLI 素材包登记仍可用。

网页头像选择器从私有素材列表搜索/分页，只展示方形图片；服务端重新核对已登记素材与方形尺寸。新建使用 expectedRevision=0，修改携带当前角色版本；account-admin→content_state 锁内复核 operator 和最新版本，并与实际用户/对象/理由审计同事务提交。并发旧版本返回409，不覆盖。历史角色快照可在页面读取，即使该角色尚无声音档案；最近20个历史版本有入口，其他固定版本由 API 读取。新角色版本不自动复制旧声音档案，需要单独配置；课程快照和既有录音继续引用原固定版本。

配音档案独立存于 `character_voice_profiles`，以 `(characterId, characterRevision, voiceRevision)` 固定。包含个性、说话习惯、默认情绪、提供方、模型、音色 ID、固定/复刻类型、locale、语速及可选参考录音。参考录音引用已登记的 `audio_assets` ID/revision，附原文和用于声音复刻的授权依据；它不会把普通音频播放授权自动转换为声音复刻授权。参考录音暂限30秒，已支持在录音管理上传、限时交付、远程创建/状态核对，以及私有克隆试听和人工确认追加声音版本。系统音色通用网页候选试听现已接入，真实音质验收和正式课程录音覆盖仍待完成。

管理员可在 `/admin/recordings` 上传并搜索固定版本，查看来源、许可与解码元数据并私有试听。声音档案中的参考选择器可以搜索/分页、试听并选择30秒以内的固定版本；替换录音会清空原文和复刻授权，须重新核对填写。保存时服务端再检查版本存在和时长上限。选择器不会创建提供方音色；播放授权不能代替复刻授权，登记通过也不表示满足提供方录音质量要求。

编辑总是追加新版本，理由和真实管理员 ID 与档案同事务保存，进入后台历史页。数据库拒绝 UPDATE/DELETE；写入持有 account-admin 锁复核当前权限，expectedVoiceRevision 保护并发修改。旧角色/声音版本可由固定版本 API 读取；列表每次20个角色，显示各角色最新角色版本及其最新声音档案。当前页面展示最近20个历史声音版本，其他固定版本可通过 API 读取。不存在“最新声音自动覆盖旧音频”。

## 一致语音生成

`voices.json` 是 Camille/Luc 的初始配音方向，沿用用户认可的两个法语音色，新的个性指令尚未重新生成试听。Léa 尚未选择独立声音，不能把 Camille 的试听当成 Léa 已通过的声音。

后台可以导出本页已配置档案，或导出单个固定版本。导出仅存于管理员主动下载的文件，不写浏览器持久存储。面包店试听生成器默认读取仓库初始档案，也可明确传入后台导出文件：

```powershell
node scripts/qwen-tts.mjs --plan --profiles <character-voices.json>
node --env-file=.local/tts.env scripts/qwen-tts.mjs --generate --profiles <character-voices.json>
```

面包店脚本按固定角色 Camille v1、Luc v1 解析档案。每个角色必须恰好有一个声音版本，缺失/重复或不支持的模型在计费调用之前失败。复刻档案须有参考原文与授权，生成前查询提供方状态和绑定模型。角色特点和默认情绪与每句话的场景情绪共同形成指令；音色、模型、语速均读取档案。生成回执记录三重版本、完整参数与档案哈希，原始录音保留。这里只是面包店试听生产工具，尚未覆盖全部课程、Léa、词级时间轴或正式音频发布。

提供方的模型名可能是可更新别名，固定档案只能稳定生成配置，不能保证重新生成的声纹/波形完全不变。正式课程应固定审听后登记的录音版本与文件哈希，保留原文件，而不是上线时重新请求 TTS。

本机 CLI `character-voice-import <request.json> <operator-email> <reason>` 复用网页相同校验和事务，用于初始化实际角色档案；请求遵循生成的 `AdminCharacterVoiceRequest`，不绕过 operator、角色登记或版本冲突。它不调用提供方、不生成录音、不修改已发布课源。

## 本次指南核对与角色配音约定（2026-10-07）

依据用户再次提供的[阿里云声音复刻指南](https://help.aliyun.com/en/model-studio/voice-cloning-user-guide)，当前北京支持列表包含 `qwen-audio-3.1-tts-flash`，Qwen-Audio-TTS 参考录音语言包含法语；`qwen-audio-3.1-tts-next` 未列在该复刻支持列表内。创建时的 `target_model` 必须与后续合成模型完全一致，不能复用同一音色 ID 切换模型。采用 Flash 法语复刻，仍需实际试听验证发音和情绪，语言支持列表不证明某个参考样本的质量。

角色库继续维护姓名、头像、个性、说话习惯和默认情绪，声音档案另行固定模型、音色 ID、参考录音版本、原文与复刻授权。课程每句只引用固定角色/声音版本并补充场景情绪；角色的长期个性与一次对话的临时情绪分开。复刻用于维持声音特征，不能据此保证任意情绪指令都准确实现。

参考制作采用每个角色独立的一段完整、连贯法语：建议10–20秒、至少5秒连续清晰单人语音，停顿不超过2秒，正常语速且避免音乐、噪声或其他人声。优先保持角色自然语气，完成句子而非拼接几个孤立词。指南允许最多60秒，本项目交付仍限制30秒；指南支持M4A，本项目当前交付仅支持已登记录音中的16-bit PCM WAV与MP3。不能把提供方支持范围冒充应用已实现范围。

同一固定候选至少试听问候、礼貌请求、疑问和告别，核对音色一致性、法语发音与情绪变化。接受后追加声音版本，再独立生成/审听/登记正式课程录音；已有声音及课程版本保持不变。用户认可面包店混合试听只代表接受该样本方向，混合多角色文件不作单个角色的复刻参考。

提供方一年未用于合成的音色可能被自动清理，生成前继续查询状态与绑定模型；正式课程保留审听后的录音文件、原始AI标识和哈希，不依赖上线时重新合成。此次只核对官方文档与已有实现，没有发送创建/合成请求或更改生产数据。

## 声音复刻

用户提供的[阿里云声音复刻指南](https://help.aliyun.com/en/model-studio/voice-cloning-user-guide)列出北京地域 Qwen Audio 3.1 Flash，创建接口是北京业务空间 `/api/v1/services/audio/tts/customization`。使用 `voice-enrollment`、`create_voice` 和明确的 `target_model`，之后合成使用返回的 `voice_id`；创建和合成必须绑定相同模型。北京与新加坡支持范围不同，不把 Qwen Audio、Qwen3-TTS VC 和 Realtime 的请求混用。

文档建议10–20秒参考，至少5秒连续清晰的单人语音，避免背景音乐、其他人声音和过长停顿。现有13.12秒混合对话含多个角色，不能作为单个角色参考。生产档案可以登记人工创建的复刻音色及其参考，生成器已支持通过提供方查询的 Flash cloned 档案；尚未发送任何复刻请求、上传私人录音或验证复刻法语/情绪效果。后续适配应先核验目标模型与音色绑定、参考文件授权/解码/哈希，再为每个角色单独试听。

### 复刻接入流程（部分实现）

2026-10-07 再次核对上述指南。Qwen-Audio-TTS 接收16-bit WAV、MP3或M4A，文件不超过10 MB、采样率至少16 kHz；双声道只处理第一声道。提供方最长60秒与本项目当前30秒参考上限是两个不同约束，登记成功仍不证明录音满足复刻质量要求。

后台流程采用「选择角色固定版本 → 选择已登记参考录音并核对复刻授权 → 创建音色 → 法语试听 → 确认后追加声音版本」。限时参考交付、创建任务、私有克隆试听和确认追加版本已实现，入口分别为 `/admin/voice-references`、`/admin/voice-jobs`、`/admin/voice-auditions`。真实参考录音的复刻及人工听感验证尚未执行；手动填写音色 ID 不等于完成此流程。

- 创建任务固定参考录音版本/哈希、区域、目标模型与实际管理员；返回音色 ID 后查询提供方详情，核对绑定模型，再进入试听。保留请求 ID 和任务状态，秘密及参考文件临时访问地址不进入公开课程或审计日志。
- 参考录音保持私有。Qwen-Audio 接口需要可访问的音频 URL，已实现下述限时交付机制；现有私有媒体接口仍要求管理员身份，不能套用 Qwen3-TTS 的 data URI 请求。创建任务已接入限时地址，真实提供方创建尚未执行。
- 超时或响应丢失先核对提供方音色记录，不能直接重复创建。试听未通过时保留旧声音版本；通过后创建新的 voiceRevision，后续生成明确选用该版本。
- 复刻固定音色特征，每句情绪仍由场景指令控制。参考使用角色自然语气，分别试听问候、请求、疑问和告别，核对法语发音及跨情绪的一致性。
- 提供方音色删除或不可用时暂停新的生成，不改已发布录音。复刻任务、音色与最终音频登记分别记录；只有生成成功、审听和固定音频发布都完成，课程才使用新声音。

当前继续沿用已试听的两个系统音色；此设计没有触发新的 API 计费请求或上传参考录音。

本次核对：指南的北京支持列表明确包含 `qwen-audio-3.1-tts-flash`，未列出 `qwen-audio-3.1-tts-next` 的克隆支持，不能仅因模型能够合成就推断能够复刻。音色 ID 与模型绑定，跨模型须分别创建；提供方可能清理一年未使用的音色，生成前应查询可用性，保留已登记录音。提供方查询、受限参考交付、远程创建任务和私有克隆试听后台已实现；真实复刻、角色声音审听及正式课程录音覆盖仍待完成。

### 已实现的提供方可用性核对

`scripts/qwen-voices.mjs` 调用北京业务空间的 `voice-enrollment` 查询接口，不创建、修改或删除音色。依据[声音复刻 HTTP API](https://help.aliyun.com/en/model-studio/voice-clone-design-http-api)，列表使用 `list_voice` 与从0开始的页码，详情使用 `query_voice`。列表没有模型绑定信息，不能用列表中的 OK 代替详情校验；满页仅说明可能还有下一页，不冒充总数。

```powershell
node --env-file=.local/tts.env scripts/qwen-voices.mjs --list 0
node --env-file=.local/tts.env scripts/qwen-voices.mjs --query <voice-id>
```

面包店生成器对 `cloned` 档案先验证固定参考版本、非空原文与复刻授权字段，再查询详情。仅状态 `OK` 且 `target_model` 与档案完全一致时合成；`DEPLOYING`、`UNDEPLOYED`、未知状态、模型不一致或读取失败均在合成前拒绝。整批开始前核对所有所需角色，每句生成前再次核对，记录脱敏的 requestId、model、status、checkedAt。记录授权文本不等于独立法律审查，也不替代正式登记的来源及文件校验。

查询只向允许的北京 HTTPS 业务空间发送 API Key，禁止重定向，响应不超过256KB且30秒有界；错误不输出提供方原文、密钥或参考录音 URL。结果明确丢弃 `resource_link`。查询失败没有自动重试或触发创建；原系统音色不增加复刻查询。离线 `--plan` 不访问网络，不能证明复刻音色当前可用。

2026-10-07：16项语音协议测试通过，覆盖上述拒绝条件、全部角色预检、合成顺序与收据脱敏。实际凭据成功读取第一页，当前列表为空；未创建音色或生成新音频，未验证真实复刻发音。这段记录对应当时仅维护档案和参考选择的阶段；现有远程任务及试听页面的实现见下文，不将 CLI 测试当成真实复刻音质验证。

### 限时参考录音交付（已实现）

`/admin/voice-references` 管理交付记录，角色固定声音版本的“参考录音交付”入口可签发地址。仅当前管理员可操作，须再次确认单人录音及向 Qwen 交付授权、填写理由。服务端固定角色/声音/录音版本及授权快照，重新读取实际文件、核对哈希并完整解码：5–30秒、至少16kHz、最多10,000,000字节；WAV必须为16-bit PCM，另支持已登记录音中的MP3。清晰单人及权利依据仍需人工核对，解码检查不证明录音质量或法律授权。

地址包含256-bit随机访问凭据，有效15分钟，最多32次文件请求（HEAD和Range同样计数），不是单次读取地址。数据库只保存凭据哈希；签发响应只显示一次完整地址，列表、SSR与审计不返回它。当前管理员可以撤销，同一固定声音版本仅允许一条未过期且未撤销的交付。每次读取检查签发者当前operator权限、期限、撤销及剩余次数，并再次校验文件；账号锁与撤销串行化，读取提交后已取得的文件无法收回。暂停管理员权限期间拒绝读取；权限恢复不等于撤销凭据，永久取消须显式撤销。

迁移18新增不可变交付、撤销与读取记录，审计包含真实用户、对象和理由；已有交付时回滚拒绝删除记录。应用日志不记录原始路径中的凭据，外部代理日志应保留相同脱敏边界。能力地址的持有者可在有效期内读取对应文件，无需用户Cookie；它不公开录音目录或其他文件。此功能只交付已授权参考，不调用付费创建、生成试听或发布课程。

### 后台音色创建与结果核对（2026-10-07）

在固定声音版本签发参考地址后，可以再次确认可能计费并创建Qwen音色。Rust客户端使用北京业务空间、voice-enrollment/create_voice、精确Flash模型、法语language_hints与30秒参考上限。创建任务先持久化再发送，每个交付凭据只允许一个任务；2个并发许可、10秒连接/30秒请求/35秒任务等待、256KB响应、TLS和禁止重定向/代理/自动重试限制提供方边界。请求中的参考地址只在内存持有，不存入任务、事件或日志。参考文件和原授权在请求提交前再次检查；已经发送的外部创建不能因页面关闭、账号变化或凭据撤销而撤回。

迁移19保存不可变voice_clone_jobs/voice_clone_events，固定交付记录间接绑定角色、声音、录音和授权快照，保存真实管理员/理由、独立音色前缀及脱敏回执。页面/admin/voice-jobs支持20条游标分页、固定任务读取和状态核对；SSR只读取，不发提供方调用。提交或核对超过60秒无结果显示unknown，进程退出不自动恢复发送。超时、连接失败、5xx、未知或损坏响应均视为结果不明确；提供方明确拒绝才显示failed。丢失响应时须在提供方控制台找到任务前缀对应的音色，填写ID和理由，通过query_voice核对；找回不会再次create_voice。同一grant冲突也不能冒充创建成功。

提供方返回的voice_id须符合任务的模型/前缀，状态核对只有精确绑定模型与OK可进入ready；DEPLOYING、UNDEPLOYED、不一致模型与查询失败分别保留状态。checking使用expectedVersion与固定任务锁防覆盖，迟到工作结果不得覆盖后续核对。客户端等待期间只轮询本服务记录，不自动查询提供方。ready表示当前已查询可用，尚未试听、追加角色声音版本或应用到课程；后续合成仍需重新核对提供方可用性。

私有配置通过可选compose.tts.yaml仅传给Rust server：生产维护命令在compose.yaml和compose.https.yaml后追加-f compose.tts.yaml，来源为被忽略的.local/tts.env；不打印合并后的config或容器环境。开发需显式加载相同私有变量；DASHSCOPE_BASE_URL或QWEN_WORKSPACE_ID限定北京HTTPS业务空间，PUBLIC_APP_URL为参考交付的HTTPS origin。未配置时可以读任务但不能创建或核对，非法显式配置在服务启动时拒绝。不把密钥传给Web、迁移或共享.env。
