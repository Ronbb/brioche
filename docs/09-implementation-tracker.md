实际证据见 `07-design-verification.md`。外部条件（正式域名、端口、人工教学审校和真实 iPhone）应明确记录，继续实现不依赖它们的工程工作；不得因此把产品范围缩小到演示。

作者工具进展：已有数据库无关的 check/check-release、严格审校元数据与 Rust 生成的作者 Schema（包含私有规则，保留在 docs）；仍需完整语义错误定位、staging 预览、录音与正式教学内容，不能据此判定内容发布工具全部完成。

预览进展：operator 固定 revision 页面与课程范围内的私有媒体已接入，权限/降权/撤回/答案隔离通过 PostgreSQL 验证；整批 staging release 目录、题目交互判分与浏览器体验验收仍待补齐。

整批预览进展：已接入按不可变清单排序的 operator release 目录与固定版本课程链接，撤回课程保留标注；未激活批次的权限/版本/顺序/不改变线上状态已通过 PostgreSQL 验证。题目交互判分和浏览器体验验收继续待补齐。

题目预览进展：三类题型的 operator 判分已接入正式 Grader，权限/CSRF/版本/撤回及不写学习记录通过 PostgreSQL 验证；浏览器真实交互、失败与退出流程仍待验收。

预览浏览器进展：批次入口/三类题判分、网络失败保留答案和恢复重试、刷新丢弃预览草稿、退出后拒绝、四档宽度无横向溢出已在隔离浏览器验证；修复网络错误 toast。完整可访问性、私有图片、跨标签身份变更、迟到响应和真实 iPhone 仍待验收。

录音契约进展：已加入音频固定描述、正文时间轴、整句/语块/Unicode 单词区间契约与语义校验，空字段保持旧版本文档兼容。满足登记、授权、文件与课程审校条件的录音课程现可发布；前端统一播放器已接入，完整设备与可访问性验收继续进行。

录音文件进展：新增无数据库的 `audio-check`，完整解码 MP3/WAV、计算真实时长与哈希，并拒绝截断/格式伪装/非法声道采样率/超大超长文件。实际 MP3 合成文件与内存 PCM 测试已通过。

录音后端进展：不可变 audio_assets/audio_import_audit、audio-import、audioRefs 固定版本投影、发布的登记/哈希/解码检查、公开单段 Range/HEAD 和课程范围内的管理员私有音频已接入。PostgreSQL 验证并发唯一/整批回滚、撤回、降权、未公开登记/staging、课程范围、腐坏文件、206/416/ETag/If-Range；迁移 up/down 和现有身份/学习/发布集成测试通过。

录音前端进展：点词/头像/全文已接入共用录音协调器与媒体时间轴，录音调速/暂停保留位置，全文复用同一媒体元素，词 ID 包含 entry 避免冲突，缺词 cue 仅合成所点词。五项播放器协议测试覆盖迟到事件、暂停中 play Promise、元数据/EOF/异常/外部暂停、Unicode 和片段选择；真实浏览器通过公开录音点词区间/头像译文/全文/短文/暂停调速/快速切词、腐坏文件错误与恢复，并查看 390px 同步高亮截图。账号学习点词/头像/全文、切步骤停止与实际进度核对，管理员私有预览切 revision/退出/降权停止和重新授权，以及键盘调速选择/取消/焦点返回已实测。完整可访问性、背景行为、有法语声音设备回退、真实 iPhone 和正式审校录音仍待完成，录音功能保持部分实现。

身份同步进展：跨标签认证变化通知、聚焦/可见身份探测、可见 30 秒检查、pagehide 清理与 BFCache 恢复重新授权已实现。五项协议测试覆盖账号切换/退出/降权、网络失败、去重、隐藏标签不轮询和迟到响应；真实隔离浏览器已验证管理员私有录音播放期间另一标签退出，以及服务器降权后返回标签，两者均暂停原生媒体并释放来源，移除私有正文并显示登录/权限要求。完整背景/iPhone 行为仍待验收。
