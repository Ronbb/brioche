# 实现与验收清单

更新：2026-10-06。目标保持为完整产品功能，不以“演示可用”代替多用户学习闭环。范围来源为产品、架构、课程契约、体验、部署和路线图文档，以及用户已确认的交互。以下“部分”均不能作为完成验收。

| 功能 | 状态与剩余工作 | 完成门槛 |
| --- | --- | --- |
| 工程与 SSR | 已有 Rust/Web/生成公共契约/CI | 类型检查、构建、Rust 检查及 CI |
| 邀请、登录、退出、恢复 | PostgreSQL 会话适配/迁移与 CSRF 基础已验证；认证路由待接入 | 一次性 token、Argon2id、会话轮换/撤销、登录限流、所有写请求 Origin+CSRF、跨用户隔离 |
| 个人资料与学习设置 | 临时阅读偏好已实现；账号设置待实现 | 昵称、IANA 时区、学习目标、译文/语速跨设备保存，退出清理私有状态 |
| 等级/单元/课程目录 | 部分；当前读取已发布最新 revision | 完整目录顺序、active release、空态/撤回、课程搜索 |
| 课程解释器 | 部分；正文、知识锚点与教学块已有组件 | 全部步骤可遍历，多个正文块、不依赖示例课硬编码，新课程数据即可渲染 |
| 点词/头像/全文朗读 | 浏览器合成与自定义速度面板已实现 | 真实 iPhone 验证；录音媒体、缺媒体回退及同步能力按内容规划补齐 |
| 练习 | 三类 Rust 判分和示例流程已实现；真实提交待实现 | 会话固定版本、事务记录首次/重试/提示、幂等、冲突、失败保留答案，客户端不可提交分数 |
| 进度与续学 | 待实现 | 必需步骤+题目尝试策略、单调完成、首次完成不覆盖、跨设备恢复、两标签页冲突 |
| 收藏与复习 | 临时示例自评已实现；账户排程待实现 | 稳定知识 ID 去重、UTC 到期/IANA 本地日、1/3/7/14/30 日档位、每天推荐 10 项、幂等/版本锁 |
| 首页与学习概览 | 部分；静态推荐和示例入口 | 实际续学/到期队列/周学习记录、真实目标数据、无虚构掌握分数 |
| 发布工具与内容管理 | 部分；CLI 不覆盖导入与私有规则校验 | 内容哈希/媒体授权/角色库、完整 Schema+语义检查、原子 release/回滚/硬撤回、审计 |
| 教学内容 | 仅一份未人工审校示例 | 首版 A1 三单元 12–15 课审校；完整 A1 与 A2 试点按产品规划制作，法语审校不能伪造 |
| 视觉与可访问性 | 已迁移品牌/头像/SVG/动效/覆盖滚动条 | 320/390/768/1440、键盘、reduced-motion、弹窗焦点、无溢出，真实 iPhone 补验 |
| Docker Compose 与运维 | Traefik HTTP 30075；HTTPS 由用户外部处理 | 媒体卷、镜像 digest、备份/恢复演练、日志限额、用户外部入口对接与公网验收 |
| 观测与安全边界 | 部分；错误与健康检查基础 | requestId/请求耗时、无秘密日志、body/pool/hash 并发限制、private/no-store、监控与恢复 |

实际证据见 `07-design-verification.md`。外部条件（正式域名、端口、人工教学审校和真实 iPhone）应明确记录，继续实现不依赖它们的工程工作；不得因此把产品范围缩小到演示。
