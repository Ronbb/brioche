# 界面与插图设计

## 视觉方向：一本可以走进去的生活读本

Brioche 的名字带来温暖、日常和一点法式烘焙联想，但课程题材不限于食物。采用暖橙、奶油白和浅金作为品牌主色，嫩绿作为辅助色，搭配有留白的场景插图、清晰的法语正文和安静的阅读布局。

避免所有页面都是小卡片拼成的仪表盘；大插图负责交代场景，课程列表负责找到内容，阅读页面让文字成为主体。游戏奖励和装饰不遮挡学习。

本目录中的 [交互概念稿](preview/index.html) 展示首页、阅读、练习三个状态。它使用设计示例数据和矢量场景，交互只在本地切换，不含登录、真实进度、后端或正式课程解释器。

## 页面与导航

| 页面/计划路径 | 主要信息 | 主要操作 |
| --- | --- | --- |
| 今天 `/` | 最近学习、今日到期复习、下一堂场景课 | 继续学习/开始第一课 |
| 课程 `/learn` | A1/A2、单元、课程列表和学习目标 | 切等级、查看单元、进入课程 |
| 单元 `/learn/:level/:unit` | 单元场景插图、课程目标、已完成数量 | 选课、继续该单元 |
| 阅读 `/lessons/:lessonId` | 场景、正文、步骤、知识解释 | 点词、看译文、听音频（有时）、下一步 |
| 会话 `/sessions/:sessionId` | 固定版本的课程与个人进度 | 续学、提交练习、查看反馈 |
| 复习 `/review` | 当天到期表达，原句和来源 | 看释义、不会/会/熟悉 |
| 我的 `/me` | 头像、昵称、母语、学习目标、阅读偏好；后续收藏与账号 | 查看个人信息、改偏好、返回学习 |

桌面一级导航为“今天、课程、复习、我的”；小屏可用底部导航，课堂中收敛为返回、步骤和退出。课堂路线不叠加复杂全站导航。

访客能看目录和示例正文；保存个人学习时进入登录/邀请流程。零进度首页直接推荐第一课，不显示空图表。A2 内容未制作时显示“规划中”和目标，不展示伪造已可学习的课程按钮。

## 首页

上方简洁问候和“今天用法语做一件小事”。主视觉展示当前单元的生活场景，配题名、目标和“继续学习”；旁边或下方显示当前步骤与最近保存状态。第二层是到期复习入口和本单元课程序列，最后才是其他单元探索。表达卡片整张点击展开释义，再次点击收起，不放独立“想一想”按钮；采用原生 button 语义，支持 Enter/Space，展开状态通过 aria-expanded 表达。

真实进度只显示有意义的信息：如“早餐与面包店 · 完成 1/4 课”，不摆放没有依据的能力分数。预计时间说明是编辑建议，不伪装为计时结果。

## 课程阅读

桌面为正文 + 右侧知识栏，正文宽 600–720px，右栏 280–340px；整体最大宽约 1180px。上方有场景题名和简洁朗读控制，情境插图占第一屏的一部分而不是整个屏幕。

- 对话开头集中展示角色头像、姓名与当次身份，正文轮次只保留头像和话语。点击头像展开该轮译文并朗读，不重复展示姓名、身份、播放徽标或语言按钮。短文仅排版完整句子/段落，不套用对话头像与角色布局；保留点词朗读。
- 对话头像与正文首行行框居中对齐，固定 44px 首行高度，不随换行或展开译文垂直移动。按钮用清晰动作文字，省去装饰箭头；剩余操作图标只使用 SVG 路径，不使用字体或字符图标。
- 每个法语单词可点击朗读，目标表达保留浅下划线；不显示“点击带下划线的表达”等教学操作提示，不添加“按自己的节奏”等占位文案。
- 点词后右栏显示释义、词性/性别、例句和收藏；解释与关联语法紧邻。
- 全局“默认显示中文译文”只放在设置页，从顶部设置图标进入；阅读页没有全局或逐句语言开关。头像展开译文不改变全局偏好，短文默认译文遵循设置。当前原型设置只在本次页面会话内生效。
- 手机上知识栏变成可关闭的底部抽屉，保留所点句子的上下文；正文不横向滚动。
- 多个 block 可组成一页，按钮描述具体动作，如“读完了，理解表达”，不始终写“下一步”。

示例中点击 `Je voudrais` 会显示“我想要……”以及礼貌请求说明；它不是随意翻译成汉语后就结束。用户还需要知道冠词、商品数量与服务场景的语气。

## 练习与反馈

一道题一个主要任务，上方保留紧凑的书本 SVG 图标 + “原文”入口，在同页面板查看原对话，关闭后保留已选答案和题目位置。选项行或输入框有充分触控面积。提交后显示选择是否合适、原因和正确形式；不靠红绿颜色区分。重试不抹掉首次表现。

单选未选项、填空空白、排序缺词都不能提交。文本输入支持法语重音字符辅助按钮，但不强制用特殊键盘。排序同时提供按钮移动方式，拖拽不是唯一操作。

等待时按钮显示提交中；失败保留答案和重试入口；成功写入服务端后才显示已保存。只用本地示例交互的概念稿不模拟真正的网络保存成功。

总结页回顾“现在你可以……”，列出少量关键表达、可选生活任务及“完成课程”。错误不阻止学习结束；完成与后续复习相连接。

## 设计 token 提案

| token | Light | 用途 |
| --- | --- | --- |
| canvas | `#F7F2E7` | 温暖纸色背景 |
| surface | `#FFFAEF` | 阅读面板和必要的卡片 |
| ink | `#38291F` | 正文、标题 |
| muted | `#695842` | 次要文字，仍需核对对比度 |
| primary | `#FFA62F` | 主要按钮，搭配深棕文字 |
| accent | `#9C4E27` | 阅读链接、焦点与小文字强调 |
| accent-soft | `#FFE8C8` | 情境标签、表达高亮 |
| line | `#E9D9BB` | 分隔线和边界 |
| leaf-soft | `#ACD793` | 单元插图背景与阅读提示 |

暗色模式后续以深焦糖表面、奶油正文和浅金强调建立独立 token，不机械反转插图。概念稿先验证浅色品牌方向；正式组件需支持系统主题。

字号：法语正文桌面 20–22px、小屏 18–20px；中文解释 15–16px；辅助文字不低于 12px。正文行高约 1.7–1.9，法语对话轮次之间留足空间。UI 优先 Apple 系统字体：`-apple-system, BlinkMacSystemFont, system-ui`，中文沿用设备系统字体；法语标题/正文使用 `ui-serif`，非 Apple 平台回退 Georgia。无需下载 SF 字体。参考 Apple 的清晰层级、轻量工具栏和分段选择器，保留 Brioche 的暖色与原创插图。

组件圆角 12–20px，边界和轻阴影只用于明确容器；同一屏不要堆多种投影。按钮动作色统一；正文和插图不抢夺动作优先级。

## 插图系统

品牌色参考用户提供的第一组：暖橙 `#FFA62F` 用于主按钮，浅金 `#FFC96F` 用于品牌标记、插图和朗读高亮，奶油 `#FFE8C8` 用于知识面板，嫩绿 `#ACD793` 用于整张表达卡片。阅读底色采用 `#FFFAEF`，深棕 `#38291F` 用于正文与橙色按钮文字；深焦糖 `#9C4E27` 用于可读的小文字强调，深绿 `#3B572B` 用于绿卡文字。亮橙和浅金不用于浅底小文字。页面采用同一套 token，避免每块内容各有一套色彩。

朗读采用一个播放器协调单词、整句和全文，切换请求取消旧播放。全文按正文顺序播放，播放器仅使用细进度线与 SVG 播放/暂停标记，整个区域点击播放或暂停。长按约 550ms 打开统一的自定义速度选项面板，移开/滚动取消长按，抬手不能误触播放；键盘 Shift+F10、右键及设置页提供速度入口。播放中变速从当前话语重读，暂停时变速保留暂停状态；切换正文/页面结束旧播放。进度以当前内容位置表示，浏览器 TTS 无 boundary 事件时按已完成话语更新，不虚构时间。角色与轮次作为无障碍状态播报，播放错误采用浮动 toast，保留隐藏的播放器状态播报。仅收到播放事件后显示动态高亮；逐词高亮依赖声音引擎的 boundary 事件，缺少时只突出当前话语。无音频/法语声音显示清晰状态，不模拟播放。正式版本优先审校录音或固定合成资产，浏览器语音仅为当前原型演示。

动效以 160–240ms 的状态过渡、抽屉进出、译文展开、按钮按压为主，当前播放头像轻微呼吸；遵守 `prefers-reduced-motion`。图标统一 SVG 线条系统。iPhone 使用 `viewport-fit=cover` / safe-area，操作按钮至少 44px；正文中的词维持自然排版，正式版本须验证邻近词命中与选择文本体验。

参考：[Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography)、[Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[Web Speech 标准](https://webaudio.github.io/web-speech-api/#tts-section)。

插图用于理解角色、物品和空间关系，不只是装饰。主要风格是简化几何形体、少量纸感和柔和色块；可采用原创 SVG 场景与统一风格的 raster 主视觉，正式素材由风格验证后选定。

| 资产 | 场景 | 设计约束 |
| --- | --- | --- |
| 单元封面 | 面包店、地铁、厨房、共享公寓、城市周末 | 横向 3:2 或 16:10；可裁切留白区域，主体在安全区 |
| 课程情境 | 顾客与店员、问路、朋友约见 | 重点物品和人物姿态可辨认；不过度拥挤 |
| 词汇小图 | 面包、车票、水果等具体名词 | 固定风格、透明或纯色底；抽象词不强行配图 |
| 空状态 | 尚未收藏、暂无到期复习 | 小型图，不抢主要操作 |

每课不强制制作独占大图；单元大图可复用，课程可裁切或使用小场景，降低内容扩展成本。图中不要生成关键法语文本，文字由页面排版，避免错误拼写和无法翻译。需要阅读招牌/菜单时，使用可审校的文字层。

建议第一轮素材：面包店清晨、城市通勤、家中早餐桌三张单元封面；两位顾客/服务角色、面包/杯子/车票几个局部。画面避免将所有法国生活都画成巴黎旅游名片；角色年龄、肤色与生活方式适当多样。

媒体 manifest 保存 asset ID、内容哈希、源文件/生成来源、授权/署名、尺寸、alt、衍生格式。插图本体按 WebP/AVIF 或清理后的 SVG 提供，页面预留宽高避免布局跳动。SVG 必须清理脚本、外部引用和事件 handler；内容作者不能上传任意可执行 SVG。信息性插图有 alt，纯装饰图 alt 为空。

音频与插图都遵循“有资产才展示功能”：缺音频不展示播放按钮，图片加载失败显示简洁回退并保留正文学习目标。

## 无障碍和边界状态

以 WCAG 2.2 AA 为实现目标，正式开发时按 [W3C 指南](https://www.w3.org/TR/WCAG22/) 验证。关键文本对比度、焦点可见、键盘流程、触控范围和语义结构需要实际检查，不能仅靠配色表宣称合规。

- 法语正文 `lang="fr"`，中文说明 `lang="zh-CN"`，便于正确朗读。
- 点词可以键盘聚焦，抽屉管理焦点且关闭后回到触发词。
- 不自动播放音频；动效尊重 reduced-motion。
- 320px 小屏到宽桌面均无水平溢出；表单错误和反馈有可读文字。
- 退出、刷新前不拦截已保存状态；未保存操作明确提示。
- 会话失效保留当前内存答案并提示重新登录；切换用户不能显示前用户学习数据。
- 内容版本不支持、撤回、接口不可用都有独立状态和返回目录路径。

这些交互在正式实现时需要浏览器和真实移动设备验证；概念稿仅用来讨论页面密度、文字关系和视觉方向。

## 动效补充

- 页面切换先显露标题，再依次显露主视觉、操作和次级内容；时长约 200–480ms，插图入场约 700ms。
- 整张表达卡片展开/收起采用 320ms 高度过渡，快速重复点击从当前高度继续，答案与 aria-expanded 立即同步。
- 按钮有按压缩放和由触点扩散的浅波纹，桌面卡片有轻微悬浮；正文与头像首行位置保持一致，头像仅作按压缩放与播放光环。
- 阅读切换使用轮次依次淡入，译文/练习反馈/抽屉/原文与速度面板有独立过渡。播放标记只在播放/暂停图形改变时出现动效，不随每个 boundary 事件反复重播。
- CSS 和 Web Animations 都尊重 prefers-reduced-motion，运行中启用时立即取消动画，保持所有交互和内容状态。

## 错误与速度选择

语音不可用等短暂错误使用顶部浮动 toast，不插入正文布局；同类提示复用同一条，约 5.5 秒自动关闭，也可手动关闭。鼠标悬停或键盘焦点进入时暂停自动关闭，不抢用户焦点，使用 polite live region 播报。仍需用户纠正的表单错误保留原位提示，不一律改成短暂 toast。

设置入口与播放器长按共用自定义速度面板，采用 radio group、统一选中底色及 SVG 勾选；不用系统 Select。打开时聚焦当前选项，方向键/Home/End 改选，Enter/Space 确认并关闭，Esc/外部点击取消面板。变速保持既有播放协调与暂停状态。

概念稿移除没有实际跳转功能的六步示意；课程源中的步骤数据保留。未来只有在真正支持导航、进度或续学时才显示相应步骤 UI。

## 复习与个人页 demo

复习导航进入独立页面，使用示例课程 reviewItemIds 指定的 3 个表达。整张卡片点击揭示/收起含义、说明和原句；揭示前无法自评。选择“还不熟 / 有印象 / 记住了”后进入下一项，新的答案保持隐藏，不继承阅读页全局译文偏好。支持当前表达朗读、轮次进度、完成回顾、只重练未熟项及重新开始全部。

这些选择是本轮自评，不计算能力分数，也不模拟未来复习日期或真实账号保存。离开再回到复习保持内存中的当前卡片，刷新重置。正式排程/到期队列仍由服务端按账号保存和计算。

自评采用同一圆角表面内的纵向选择行，以细分隔线、彩色圆点和 SVG 箭头区分，避免并排独立按钮。完成页只突出一个主操作：有未熟项时重练未熟项，否则重新开始；其他操作为下方文字入口。移除复习卡片底部的轮次说明与返回入口。点击卡片展开释义时同时朗读当前表达，移除独立喇叭按钮；收起时停止朗读。

复习卡片以约 420ms 平滑展开，释义、例句与选择区依次渐入；快速重复点击从当前高度继续，减少动态效果模式取消过渡。页面原生滚动行为保留，桌面细滚动条覆盖在右侧而不占布局宽度，支持拖动和键盘；手机可滑动浏览。原型的内层滚动容器隐藏原生滚动条，避免弹层和页面切换因滚动条占位改变宽度。

底色进一步收敛为暖奶油色 #FFFAEF / 浅燕麦色 #F7F2E7，品牌橙与绿继续作为操作和内容点缀。右上角由示例用户头像进入“我的”，展示昵称、母语、学习目标及阅读设置；Lin 为演示资料，尚无账号 API 或资料编辑功能。

顶部仅保留完整品牌和个人头像，移除“今天 / 课程 / 复习”导航。点击品牌返回首页，课程由首页主视觉与课程列表进入，复习由首页表达卡片下方的文字入口进入。设计预览说明与页面调试入口位于应用下方。
