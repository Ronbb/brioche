# 开发顺序与验收

## 按完整学习链路推进

下一步先实现“单个用户打开一堂数据驱动课程，读正文、看解释、提交练习、离开后继续”这一条链路。不要先把所有页面壳、所有等级或在线编辑器做完，再发现课程模型不能表达正文。

阶段没有承诺日历工期。每阶段的退出条件比时间估计更重要。

| 阶段 | 可交付结果 | 退出条件 |
| --- | --- | --- |
| 0 · 设计（已确认 Preview） | 产品、架构、课程草案、视觉概念、部署约束 | 数据草案可结构校验，关键决定及待定事项有记录 |
| 1 · 工程基础（当前） | pnpm + Cargo workspace、Vite/React Router、Axum、SeaORM migrations、同源开发 | 本机直接启动，SSR/client 构建、Rust 镜像、health/readiness 可测 |
| 2 · 课程解释器 | catalog、blocks、steps、知识锚点、公共 DTO、发布 CLI | 示例课不需专属页面代码，拒绝错误引用和答案泄漏 |
| 3 · 学习闭环 | 邀请/登录、会话、三种练习、进度和续学 | 两账号数据隔离，重发幂等，跨设备/多标签不丢进度 |
| 4 · 首版产品 | 首页、目录、复习、收藏、响应式设计与插图 | A1 三单元内容审校通过，手机/桌面可完成完整学习 |
| 5 · 本机上线 | Docker/Traefik HTTP 30075、用户外部入口对接、备份、恢复、运维记录 | 公网烟测及恢复演练通过，再发布初版 |
| 6 · 内容扩展 | 完整 A1、A2 试点、审核音频、搜索 | 内容可按数据增量发布，旧会话仍可继续 |

第 2 阶段先使用设计样例验证解释器，不把 draft 直接发布给用户。第 4 阶段制作约 12–15 堂课，保证三个 A1 单元各有可完成的任务序列；具体数量根据审校质量调整。

## 必须验证的行为

| 场景 | 预期 |
| --- | --- |
| 结构或引用不合法的课程 | 发布失败，错误定位到文件与 JSON pointer，旧 release 继续生效 |
| 新增一堂同类型课程 | 仅添加/修改数据和媒体，不改 renderer |
| 公共课 API、SSR/loader data 和客户端 bundle | 不包含 serverOnly 判题规则、运维秘密或数据库实现 |
| 用户 A 请求用户 B 的会话/卡片 | 拒绝访问，不泄露存在性或内容 |
| 写 API 缺/错 Origin 或 CSRF token | 拒绝；包括登录、邀请接受、恢复和退出 |
| 同一次提交断网重发 | 只有一条 attempt，返回第一次结果 |
| 同键不同答案 / 两标签页版本冲突 | 409，客户端刷新；不默默覆盖 |
| 填空有重音/弯撇号/空白差异 | 按明确归一化规则处理，重音不悄悄去除 |
| 学完一课 / 再次点完成 | 进度单调、复习卡去重、首次完成记录保留 |
| 发布新 revision 或回滚 release | 新会话用当前版本，旧会话按固定版本继续 |
| 硬撤回课程 | 旧会话 410，历史记录保留，关联复习停止 |
| 服务器不可用 | 内容不闪失，明确显示未保存，不能虚构保存成功 |
| 用户切换账号 / CDN 开启 | 私有缓存清理，不显示其他用户学习情况 |
| 320/390/768/1440px，键盘和 reduced-motion | 无横向溢出，关键操作和解释均可访问 |
| 备份恢复到隔离环境 | 目录版本、账号、进度和媒体哈希可验证 |

验证规模随风险增加：纯文档改动检查一致性；课程变更做结构/语义/审校/预览；事务、权限、版本变更做针对性测试和必要 E2E；不为可逆的小样式调整制造镜像实现的测试。

## 已采用的设计建议

- Vite 8 + TypeScript 7 + Tailwind CSS 4 + React Router Web；Rust/Axum 独立 API，服务端保持模块化单体。
- Rust Serde 类型导出 JSON Schema/TS/OpenAPI，公共 DTO 与私有判题模型分开；不在两种语言手写重复契约。
- SeaORM + PostgreSQL：关系表存用户状态、JSONB 存不可变课程快照；文件是编辑源，DB 是发布运行源。
- JSON Schema + 语义校验；同源 API、cookie 会话、服务端判题。
- 推荐顺序而非强制解锁；完成与掌握分开；生活任务可选。
- 初次上线邀请制；完整 A1–A2 规划、工程 MVP 先 A1 三单元。
- 温暖读本风格，单元情境插图 + 以文字为主的学习页面。

阅读交互纳入首版：角色库及发布快照、单词/话语/全篇朗读协调、译文开关、原文面板、SVG 图标与动效。首版验收增加 iPhone Safari 实机播放/暂停/续播、无声音回退、角色轮换与取消旧播放；录音扩充及精细词级同步仍为后续制作任务。Web/API 的开发启动验收须包含同网手机访问。


阅读交互验收补充：角色介绍只出现一次、头像翻译与朗读合并、短文纯段落、设置页全局译文、整条进度线点按播放/暂停、长按不误触及滚动取消、变速保留暂停。正式用户偏好由设置 API 保存，当前概念稿仅内存状态。
