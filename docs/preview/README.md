# 界面概念稿

静态设计提案，尚未使用 Vite/React 或 Rust API。首页、阅读、练习、复习、我的可切换；刷新不保存收藏、答案、设置和进度。

- 首页表达卡片整张点击展开/收起，支持 Enter/Space，没有内部操作按钮。
- `motion.css` 包含页面分层入场、卡片展开、触点波纹、头像按压、播放器光环与面板动效；减少动态效果时自动取消。
- 点击法语单词朗读；关联表达同时打开释义，手机使用底部抽屉。
- 对话角色介绍集中在开头，正文只显示头像。点击头像展开当前话语译文并朗读；短文为纯句子/段落，保留点词朗读。
- 细进度线的整个区域点击播放/暂停全文，长按弹出统一的自定义速度选项面板；右键/Shift+F10 和设置页也可调速。变速从当前话语重读，暂停状态保留；切换页面或正文结束旧播放。
- 浏览器须提供法语声音；没有声音时显示状态。当前为语音合成演示，真实 iPhone Safari 发音和暂停行为仍需实机验证。
- 全局译文开关仅在设置页；头像展开当前译文不改变全局偏好。练习“原文”打开对话面板，保留已选答案。
- 品牌样式在 `brand.css`，阅读交互在 `reader.css` / `reading.css` / `preview.js`，公共示例数据在 `preview-data.js`，排除服务端判分规则。
- `bakery.svg` 与 `avatars/*.svg` 是原创概念素材，正式发布仍需媒体 manifest。

从项目根目录启动：

```powershell
python -m http.server 4173 --directory docs/preview
```

不指定 bind，监听所有网络接口。本机打开 `http://localhost:4173/`；同一局域网手机打开 `http://<电脑局域网地址>:4173/`。可用 `Get-NetIPAddress -AddressFamily IPv4` 查看电脑地址。此服务器仅用于开发预览。

语音错误通过顶部 toast 显示，可关闭且自动消失；原型不展示无功能的步骤示意。速度面板由 `speed-picker.css` 统一样式，toast 在 `toast.css`；均支持减少动态效果。

复习页：从顶部“复习”进入，包含 3 个示例表达，整卡揭示释义后自评，完成后可重练未熟项或全部重来。仅内存演示，不生成排程或保存账号记录。`review.css` 定义复习样式。

个人页：右上角头像进入“我的”，显示示例资料 Lin 与阅读设置；原创示例头像为 `avatars/learner.svg`，个人页样式在 `profile.css`。

复习自评采用纵向列表，完成页采用单一主操作。点击卡片展开并朗读表达，无独立朗读按钮或卡片底部操作。`scroll.css` / `scroll.js` 提供不占布局宽度的页面滚动条；卡片过渡尊重减少动态效果设置。
